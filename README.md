📌 Python Mini Projects Collection
This repository contains a collection of beginner-friendly Python projects developed to strengthen core programming concepts, logic building, and hands-on problem-solving skills.
Each project focuses on practical implementation using Python and helps in understanding real-world applications of basic programming concepts.

🚀 Projects Included
✅ Task 1: To-Do List Application
A simple To-Do List application that helps users manage daily tasks efficiently.
Users can add, update, and track tasks using a command-line or basic interface.
Key Concepts Used:
Lists & Dictionaries
Conditional statements
Loops
User input handling

✅ Task 2: Calculator
A basic calculator program that performs fundamental arithmetic operations such as addition, subtraction, multiplication, and division.
Key Concepts Used:
Functions
Conditional logic
User input
Arithmetic operations

✅ Task 3: Password Generator
A password generator tool that creates strong and random passwords based on user-defined length and complexity.
Key Concepts Used:
Random module
String manipulation
Loops
User input validation

✅ Task 4: Rock-Paper-Scissors Game
A classic Rock-Paper-Scissors game where the user plays against the computer.
The program determines the winner and can optionally track scores.
Key Concepts Used:
Random choices
Conditional statements
Game logic
Loops

✅ Task 5: Contact Book
A Contact Book application that allows users to store and manage contact details such as name, phone number, email, and address.
Features:
Add new contacts
View contact list
Search contacts
Update contact details
Delete contacts

Key Concepts Used:
Dictionaries
Functions
File handling (optional)
CRUD operations

🛠 Technologies Used
Python
Standard Python Libraries
Command Line Interface (CLI)

🎯 Purpose of This Repository
To practice Python fundamentals
To build logic and problem-solving skills
To gain hands-on experience through mini projects
To prepare for internships, interviews, and real-world development
🌱 Learning Outcome
Through these projects, I enhanced my understanding of Python basics, improved logical thinking, and gained confidence in building small-scale applications from scratch.
